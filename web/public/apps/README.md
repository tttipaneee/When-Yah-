# App logos (supplied by the team)

Drop the official logo files here; the app picks them up automatically (no rebuild needed in dev):

- `grab.png` (or `grab.svg`)
- `indrive.png` (or `indrive.svg`)
- `gvride.png` (or `gvride.svg`)

Square images work best (shown in a 30–34 px circle). If a file is missing, the app shows the app's initials.
Logos are trademarks of their owners; the app states it is not connected to or affiliated with them.
